# React Practice — Vite Starter

A minimal React + Vite starter used for learning and experimenting with React. The current app displays the default Vite/React logos and a counter button.

## Tech stack

- React
- Vite
- JavaScript
- React Router dependency included in the project configuration

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Available checks

```bash
npm run build
npm run lint
```

## Status

The committed screen is still the starter example; the repository can be used for future React and routing exercises.
